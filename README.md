# Unsupervised Motion Adaptation via DC3

## Introduction
Close interaction motion adaptation aims to retarget motions involving multiple interacting characters while preserving spatial relationships between them. Unlike conventional motion retargeting, this problem requires maintaining both individual motion plausibility and interaction structure, making it particularly challenging under changes in character proportions
This project investigates a hybrid approach that combines constraint-based optimization with a learning-based solver. A complete pipeline is constructed, starting from BVH motion data, followed by skeleton reconstruction, InteractionMesh construction, and formulation of a constrained adaptation problem. A dataset is generated by varying bone-length scaling factors, and a neural network is trained to predict adapted poses within a constrained optimization framework inspired by DC3.
The results show that the proposed system is able to preserve the overall interaction structure under moderate scaling changes. However, quantitative analysis reveals that geometric constraints, particularly bone-length consistency, are not fully satisfied, especially under stronger asymmetric deformations. These findings suggest that while learning-based methods can approximate constrained motion adaptation, additional mechanisms are required to ensure reliable constraint satisfaction.
Overall, the project demonstrates the feasibility of integrating neural networks into constrained motion adaptation and identifies key challenges for future work.

## DC3
This project is adapted from DC3, but it does not need the data of simple problem or other problems defined in the original DC3 paper. For more information, visit https://github.com/locuslab/DC3/.

## Instruction
### Running experiments
Run `python method.py` in the root directory to train the model. Arguments can be changed in `default_args.py`.

Run `python predict.py` or `python predict_multiframes.py` in the root directory to predict the deformed interaction using trained model, which is defined in `results\InteractionMesh\method`

### Generate data
Run `python make_datasets.py` in the `datasets` folder. If you want to deform multiple frames, you need to code `make_datasets.py`, `method.py` and `predict_multiframes.py` and ensure them all works. Current `method.py` does the deformation on single frame.

### Visualisation
Go to Blender and import `visualisation.blender` or `visualisation_multiframes.blender` (which is used to visualise the interaction of multiple frames) in `data_blender`, then run the script. This will visualise the perdicted motion which is named in particular.
